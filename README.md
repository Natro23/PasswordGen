# Password Generator 🔐

A console based Password Generator built in C#.

## Features
- Custom password length
- Option to include numbers
- Option to include symbols
- Generate multiple passwords in one session

## How to use
- Run the program
- Choose a password length
- Choose whether to include numbers (y/n)
- Choose whether to include symbols (y/n)
- Your password will be generated instantly!

## Built with
- C#
